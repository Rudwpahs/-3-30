# 생활 중국어 기말고사 완전 정복

업로드한 기말 대비 보충자료와 중학교 생활 중국어 교과서 2~4과를 기준으로 만든 정적 학습 웹앱입니다.

## 포함 내용

- 1과 발음 보충: 성조, 성모, 운모, 한어병음 표기 규칙
- 2과 인사·감사·사과
- 3과 이름·국적·인물 묘사 및 나라 이름
- 4과 가족·나이·학년·숫자
- 필수 한자 카드 38개
- 수행평가 문장 쓰기 20개
- 실전 퀴즈 및 로컬 진도 저장
- 중국 개관 암기 카드

로그인과 서버가 필요 없는 정적 앱이며 학습 진도는 브라우저 `localStorage`에 저장됩니다.

## 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

`main` 브랜치에 푸시하면 GitHub Actions가 `dist`를 GitHub Pages에 배포합니다. 저장소의 Settings → Pages에서 Source가 **GitHub Actions**로 설정되어 있어야 합니다.
